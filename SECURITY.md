# Security policy

## Supported versions

Only the latest published release receives security fixes.

## Reporting a vulnerability

Please use this repository's **Security** tab to submit a private vulnerability
report. Do not open a public issue for suspected vulnerabilities or include
credentials, memory contents, API keys, or access tokens in a report.

Include the affected version, reproduction steps, impact, and any suggested
mitigation. You can expect an initial acknowledgement within seven days.
